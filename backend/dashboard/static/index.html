First run

Nothing is connected yet. To see this dashboard live:

1. Start capture:
python backend/run_capture.py --engine mediapipe --dashboard 8765

2. Open the demo scene in Blender with the RealCapture addon enabled, so the heartbeat starts.

3. Watch the three lights below: they only turn green when each link is actually alive.

GREENCamera — a fresh camera frame is arriving from the capture loop.
GREENPackets to Blender — capture packets are reaching Blender right now.
GREENBlender rig — the addon heartbeat is fresh and the rig bind is healthy.
YELLOWstill alive but aging; the reason text says what is slowing down.
REDthat link is down or was never seen; the reason text says what is missing.
UNKNOWNthe dashboard was told nothing about this link — never assume it is fine.
